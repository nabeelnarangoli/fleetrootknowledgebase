# Project rules (Fleetroot Knowledge Base)

- Never deploy straight away. Commit and push to `staging` only; merge `staging` into `main` (the live site on Netlify) only when the owner says "deploy". Deploy all changes together, to save Netlify build credits.
- Every guide keeps English as the main text with an Arabic line under it. Fleetroot screen labels stay in English (as on screen), in `**bold**`.
- Animated guides use real screenshots of track.fleetroot.com (demo account), never redrawn screens. Park the mouse pointer out of view before capturing, and record control positions as % of the screen.
- In Fleetroot, record actions (Edit, Delete, …) are on the right-click menu. Guides must say so.
- Customers sign up with their email and must confirm it before signing in.
